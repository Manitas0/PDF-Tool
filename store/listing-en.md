## Description

Limit: 10,000 characters – this text has about 1,850.

```text
PDF-Tool is a lean tool for merging and splitting PDF files. Everything happens right on your PC – without uploading anything, without an account and without an internet connection. Your documents never leave your computer.

Please note: the user interface of PDF-Tool is in German.

MERGE
• Add any number of PDFs by drag and drop or file picker – even the same file several times
• Change the order by dragging or with the arrow buttons, or sort by file name
• Take only certain pages from each file, e.g. "1-3, 7"
• Thumbnail of the first page and page count of every file
• Choose the file name of the result

SPLIT
• Every page on its own: one PDF per page
• Every N pages: parts of equal size
• By page ranges, e.g. "1-3, 4-6, 7-": one PDF per range
• Select pages – by clicking in the page preview or by typing – and save them as one new PDF
• The page preview shows which output file each page ends up in
• Save the results as a ZIP archive or as separate files

PRIVACY
• Processing runs entirely locally with the open-source libraries pdf-lib, pdf.js and JSZip
• No network connections, no telemetry, no ads, no account, no in-app purchases
• Result PDFs contain only the selected pages – other pages and their form values are not copied invisibly

USABILITY
• Fully usable with the keyboard
• Light and dark mode – follows your Windows setting
• Save with the familiar Windows "Save as" dialog
• For Windows 10 and 11 on PCs with Intel or AMD processors (x64) and on devices with ARM processors (arm64)

GOOD TO KNOW
• Encrypted or password-protected PDFs are not supported.
• Bookmarks and form functionality are not carried over; filled-in form fields stay visible as text.
• Very large files need a correspondingly large amount of memory.

The source code of PDF-Tool is publicly available on GitHub: https://github.com/Manitas0/PDF-Tool
```
